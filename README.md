# ASEA - Autonomous Software Engineering Agent

ASEA is an AI-powered software engineering agent designed to understand web applications, inspect UI elements, generate automation knowledge, and create engineering reports.

## Version 1 Features

- Express.js backend
- Playwright-based browser inspection
- UI element extraction
- Screenshot capture
- JSON-based application knowledge storage
- Markdown inspection report generation

## Tech Stack

- Node.js
- Express.js
- Playwright
- Groq SDK
- JavaScript
- JSON storage

## Run Locally

```bash
npm install
npm run dev
